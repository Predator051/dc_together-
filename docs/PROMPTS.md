# Готовые фразы для Claude Code

Скопируй и вставь нужную.

---

## Первый запуск

```
Ты — геймдиректор и единственный разработчик новой игры. Проект пустой, кода ещё нет.
Прочитай CLAUDE.md, все файлы в docs/ и content/secret/README.md — это правила проекта.
Коротко: кооперативная игра на двоих с сервером, на украинском языке, в сеттинге тёмного фэнтези, с жёсткими ограничениями содержания из раздела 4.
Выполни первую сессию по разделу 8 CLAUDE.md: создай проект с нуля, придумай весь мир и сюжет, сделай первый акт полностью играбельным вдвоём, напиши тесты и DEPLOY.md.
Все решения принимай сам, меня ни о чём не спрашивай. Сюжет не рассказывай.
В конце скажи только, как развернуть игру на VPS.
```

---

## Следующий акт

```
Продолжай. Прочитай CLAUDE.md, docs/ и content/secret/STATUS.md.
Сделай следующий акт по плану. Ничего не спрашивай, сюжет не рассказывай.
Наш мир на сервере должен продолжить работать. В конце скажи только, как обновить сервер.
```

---

## Если прошлая сессия не закончила акт

```
Продолжай с того места, где остановился. Прочитай CLAUDE.md и content/secret/STATUS.md и доделай текущий акт.
```

---

## Впечатления после акта

```
Мы прошли акт N. Впечатления: ...
Исправь то, что мешало играть, но не объясняй сюжет и ничего не спрашивай про него.
```

---

## Застряли

```
Мы застряли. Сейчас мы ... (что делаете и где находитесь). Дай первую подсказку.
```

---

## Похоже на баг

```
Это баг? Произошло: ... (с телефона / с компьютера, у кого из нас)
```

---

## Что-то в игре похоже на оккультизм у наших персонажей

```
В игре наши персонажи делают ...: это нарушает раздел 4 CLAUDE.md. Исправь и проверь остальной контент на то же самое.
```

---

## Хотим узнать сюжет

```
Снять печать.
```
