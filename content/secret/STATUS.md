## Технические решения

- **Стек:** TypeScript везде. Один `package.json` (без workspaces), папки `shared/`, `server/`,
  `client/`, `content/`, `tests/`, `scripts/`, `deploy/`. Относительные импорты с `.js`.
- **Сервер:** Node 24 (в Docker), `ws`, встроенный `node:sqlite` (запуск с
  `--experimental-sqlite`; на Node 24 флаг безвреден). `better-sqlite3` отвергнут: на
  локальном Node 23.2 падал с segfault. Сборка сервера — esbuild в `dist/` (`--packages=external`).
- **Клиент:** Preact + Vite, собирается в `client/dist`, отдаётся сервером. Клиент тонкий:
  получает от сервера готовый `PlayerView` (тексты уже отрендерены, чужие личные тексты и
  улики не отправляются вообще), шлёт `Command`.
- **Движок** (`server/src/engine/index.ts`) не знает сюжета: исполняет данные из `content/`.
  Подробно о формате — `docs/ENGINE.md`.
- **Время:** у каждого действия `cooldown` = время занятости игрока (все рутинные кнопки
  заблокированы, партнёр видит «рубає дрова»). `recharge` — отдельная перезарядка кнопки.
  Піч горит (топливо убывает) только пока хоть кто-то онлайн; холодная піч ×1.5 к времени.
- **День** сменяется только общим ужином (`pool_01` → сцена из пула `supper`).
- **Совместные сцены:** предложение → принятие → сцена. Текстовый узел продвигается, когда
  оба нажали «Далі». Выборы: `joint` (совпало/не совпало → mismatch-узел), `each` (каждый за
  себя, личные флаги `bg_*`), `any` (первый клик, для вопросов). При отключении сцена на паузе,
  рутина разрешена, после возвращения продолжается с того же узла.
- **Бой:** раунды, оба выбирают, сервер разрешает детерминированно (RNG мира). Победа — по
  здоровью или по страху врага. Проигрыш (все без сил или 15 раундов) — откат с потерей
  харчей, сцена не засчитывается, повторяется следующим ужином. Тупиков нет.
- **Вход:** код приглашения (env `INVITE_CODE` или сгенерированный и сохранённый в БД, печатается
  в логах). Два слота. Токен сессии в localStorage (в БД хранится sha256). С другого устройства —
  код + «Я — имя». Лимит 20 неверных попыток / 10 минут на IP.
- **Хранение:** таблица `world` (одна строка JSON), `world_archive` (снимок перед миграцией),
  `sessions`, `meta`. Автокопия БД при каждом старте (последние 10) в `data/backups/`,
  ручная — `dist/backup.js`.
- **Деплой:** `deploy/docker-compose.yml` (game + Caddy). `SITE_ADDRESS=:80` — по IP,
  `SITE_ADDRESS=домен` — авто-HTTPS. Данные в `deploy/data`. Проверено локально в Docker.
- **Имена игроков** в текстах только в именительном падеже (склонять произвольные имена
  нельзя). Род — через `{он|она}`-шаблоны: `{a|b}` — род субъекта, `{p:a|b}` — род партнёра.
- Локально порт 8080 занят чужим httpd — для превью используется 8787 (`.claude/launch.json`).

## Решения по механикам акта 1

- Ресурсы: дрова, вода, харчі, шкури, залізо, жир, стріли, смолоскипи, сильця (+на стежках).
  Скрытые запасы: погріб (12), лом у кузні (14), борошно (6). У каждого ресурса есть
  бесконечный источник (обход дворов, поиск железа по дворам, охота) — тупиков по ресурсам нет.
- Роли: Ловець — подвір'я (сліди), обхід дворів, хмиз, сильця, полювання. Майстер — дрова,
  кузня (лом, гостріння), верстак (стріли, сильця, смолоскипи), лук, криниця, дровітня,
  коптильня, укріплення. Общие — піч, вода, погріб, борошно, Сірко.
- «Виньетки» (`beats`): одноразовые сценки в рутине (обход дворов — 8, лом — 4, хмиз — 4,
  дрова — 1). Это личный контент роли, сюжет не двигают (кроме личных улик clue_37, clue_38).
- Темп по ботам: ~5–9 минут чистой «занятости» на игрока; основное время — чтение сцен и
  обсуждение. Оценка акта 1 для людей: 1,2–1,8 ч. Если игроки скажут, что коротко или
  долго, — менять стоимости в `content/act1/actions.ts` и требования сцен, не числа ×10.
