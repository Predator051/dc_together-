# Сюжетное хранилище

Здесь живёт вся правда об игре. Создаётся Claude в первой сессии. Игроки эти файлы не читают.

## Файлы

**STORY.md** — сюжетная библия: мир и его настоящая история, персонажи (желания, страхи, тайны, что знают и что понимают неправильно), фракции, враги и источник зла, главные загадки и их правда. Отдельно: чем герои противостоят злу — без оккультных средств (раздел 4 CLAUDE.md).

**ACTS.md** — план 4–5 актов. Для каждого акта: цель игроков, новые механики и локации, роли каждого из двух игроков, ключевые совместные сцены, какие улики подбрасываются (и кому — обоим или одному), какие тайны раскрываются, чем акт заканчивается, ориентировочная длина.

**REVEALS.md** — граф раскрытий. Для каждой тайны: правда, улики и где они находятся, кто из игроков их видит, ложные толкования, запасной путь для важной информации, стадии раскрытия, условие окончательного раскрытия, на что это влияет.

**ENDINGS.md** — концовки и условия, которые к ним ведут, включая совместные решения игроков.

**STATUS.md** — рабочий журнал. Читается в начале каждой сессии. Содержит:

- какие акты готовы полностью, какой в работе и где остановились;
- принятые решения по механикам, балансу, интерфейсу, технологиям, деплою;
- изменения сюжетного плана и их причины;
- подброшенные зацепки: где игроки их видели и где они должны окупиться;
- что игроки уже видели (чему нельзя противоречить);
- известные баги и отзывы игроков.

Формат файлов (Markdown, YAML) — на усмотрение Claude. Главное — чтобы следующая сессия могла по ним продолжить работу без потери согласованности.
